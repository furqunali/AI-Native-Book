# Glossary

A concise reference for the recurring terms used throughout the book.

| Term | Meaning |
|---|---|
| **AI-native application** | An application designed around AI-driven uncertainty, adaptation, and interaction rather than adding AI as an isolated feature. |
| **Agent** | A software system that selects and executes actions toward a goal, often using models and tools across multiple steps. |
| **Embedding** | A numerical vector representation of content that lets systems compare semantic similarity. |
| **Foundation model** | A broadly trained model that can be adapted to many downstream tasks. |
| **Human-in-the-loop** | A workflow where people review, guide, approve, or correct AI-driven decisions or actions. |
| **LLM** | A large language model trained to understand and generate natural-language sequences. |
| **MLOps** | Practices and infrastructure for reliably developing, evaluating, deploying, monitoring, and maintaining machine-learning systems. |
| **RAG** | Retrieval-Augmented Generation: retrieving relevant external context before generating an answer. |
| **Reranking** | A second-stage retrieval step that reorders candidate results using a more precise relevance model. |
| **Vector database** | A data store optimized for indexing and searching numerical vectors, commonly used for semantic retrieval. |
| **Model drift** | A change over time in model inputs, relationships, or behavior that can reduce production performance. |
| **Observability** | The ability to understand system behavior through logs, metrics, traces, evaluations, and other signals. |
| **Prompt engineering** | Designing and testing instructions and context supplied to a model to produce reliable behavior. |
| **Personalization** | Adapting an AI system's behavior or output to a particular user's context, preferences, or history. |
| **Tool use** | Giving an AI system controlled access to external operations such as search, APIs, databases, or application actions. |

Use the glossary alongside the chapters; definitions are intentionally concise and defer architectural detail to the relevant chapter.
